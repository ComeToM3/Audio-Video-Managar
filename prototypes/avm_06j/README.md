# Prototypes AVM-06J — isolés du moteur métier

Application de démonstration **sans** rip, SQLite métier, ni accès aux FLAC Queen.

```bash
# Depuis la racine du dépôt
python prototypes/avm_06j/run.py
```

Ouverture des références HTML (responsive navigateur) :

```bash
start prototypes/avm_06j/html/index.html
```

Ces prototypes illustrent la direction visuelle recommandée (Qt Widgets + design system).  
Ils ne modifient pas `audio_video_manager/`.
